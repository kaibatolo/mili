# Mili Commands

## Core
```bash
mili                  # pretty banner + help
mili --version        # version
mili status           # config & readiness
```

## Agents
```bash
mili agent list
mili agent show milly
```

## Chat
```bash
mili chat milly
mili chat milly "make me a taboo character"
```

## Image Generation
```bash
mili image "a girl on her knees looking up"
mili image "..." --agent milly
```
